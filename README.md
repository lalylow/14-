Программа создаёт DataFrame «База игроков», сохраняет и читает CSV,
фильтрует по условию, сортирует, добавляет колонку налога,
группирует по классу и сохраняет отфильтрованный CSV.

pip install -r requirements.txt
python main.py      

1. DataFrame «База игроков» — head(2)
2. Сохранение в dataset.csv и чтение обратно — info()
3. Фильтрация: level > 50 И klass == "Маг"
4. Сортировка по donate (убывание)
5. Новая колонка tax = 13% от donate
6. groupby: средний донат по классу
7. Сохранение игроков > 50 уровня в rich_players.csv
